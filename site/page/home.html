Everything a component needs, built in

Six ideas that show up in every one of the 45+ components in the reference.

One attribute, one contract

pgs identifies the element, pgs-option configures it, pgs-state tracks it at runtime — the same three attributes everywhere.

Dark mode, built in

Every colour ships as a light/dark pair from the start, so a component looks right in either theme with no extra markup.

Accessible by default

Semantic markup, focus states and keyboard behaviour come before any JavaScript runs, not after.

Adapts to its container

Components read their own container's width through CSS container queries, not just the page's viewport.

Nothing extra to install

Plain CSS custom properties and vanilla JavaScript — nothing to configure beyond the package itself.

Card and Box

A reusable surface for structured content, clickable or not.

Example HTML 
<article pgs="card" pgs-option="cardHorizontal">
    <img pgs="card-img imgCover" src="placeholder.jpg" alt="…">
    <div pgs="card-content">
        <h3>Card and Box</h3>
        <p>A reusable surface for structured content, clickable or not.</p>
    </div>
</article>
