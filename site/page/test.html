Last two :where() cases

The icon glyph flags (icon-*, iconDuo) and the menu link are now written in :where() as well. Check that both still look right.

Icon glyph next to an icon font

Each icon below carries the library glyph and a Font Awesome class for a different icon, so you can tell which one draws: a star or a chevron means the library, a heart or a cross means the icon font. Both weigh the same now, so the one loaded last wins. The first icon has no font class and is the reference.

iconDuo

A glyph that exists both flat and as a duo: it draws flat until iconDuo is added. The duo takes its size from --icon-size only, so it needs one here.

Menu link with the h3 utility

The links carry h3, which sets min-width: 0. The menu wants min-width: fit-content on its links: in the narrow box below the links should not shrink and cut their text (the first menu keeps its links whole, the second one is the same without h3 as the reference).
